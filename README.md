                               " Student Performance Analytics System "

About the Project :
I developed this project using Python to analyze student performance based on their marks in Python, Java, and SQL. The program calculates total marks, average marks, grades, and Pass/Fail results. It also helps identify the highest and lowest scores, subject-wise performance, and top-performing students.

Objectives :
- To calculate the total and average marks of each student.
- To assign grades based on average marks.
- To check whether a student has passed or failed.
- To find the highest, lowest, and class average marks.
- To calculate the average marks for each subject.
- To identify the top-performing students.
- To save the final results in a CSV file.

Technologies Used :
- Python
- CSV files
- Pandas
- NumPy

In this project, I used:

Files in the Project :
- "main.py" – Contains the main Python code.
- "students.csv" – Contains student details, marks, and attendance.
- "student_analysis.csv" – Stores the analyzed results generated by the program.
- "Documentation.docx" – Contains the project documentation.

Grading Rules :
The program assigns grades according to the student's average marks.
Average Marks| Grade
90 and above| A+
80 to below 90| A
70 to below 80| B
60 to below 70| C
Below 60| F

Pass/Fail Conditions:
- Pass: Average marks are 40 or above.
- Fail: Average marks are below 40.

How to Run the Project :
1. Install Python on your computer.
2. Install the required libraries by running:
   pip install pandas numpy
3. Keep "main.py" and "students.csv" in the same folder.
4. Open the terminal in VS Code and run:
   python main.py
5. The results will be displayed in the terminal, and the program will generate "student_analysis.csv".
